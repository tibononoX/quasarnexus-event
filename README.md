# Quasar Nexus Event Website

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit%20Site-blue?style=for-the-badge)](https://tibononox.github.io/quasarnexus-event/)

A stunning, modern static single-page website for the **International Summit on Space Accessibility** organized by the **Quasar Nexus Astronomy Club** at Université Centrale (Polytech), Tunis.

## 🌌 About the Event

**International Summit on Space Accessibility**  
**May 6th, 2026 • 2:00 PM**  
**Tunis, Tunisia**

A hybrid international event bringing together astronauts, space professionals, VR experts, citizen scientists, and astronomy enthusiasts.

### Key Highlights

- Keynote by **Dr. Jeffrey A. Hoffman** (NASA Astronaut)
- Immersive **VR Moon Exploration** experiences
- Citizen Science workshops with the Astronomical Society of Tunisia
- Scientific posters and interactive sessions
- Live-streamed + in-person format (English & French)

## ✨ Features

- Elegant dark space-themed design
- Real-time countdown timer to the event
- Fully responsive (mobile-first)
- Detailed program schedule
- Speaker profiles with photos
- Workshop & registration information
- Partner & sponsor section
- Smooth animations and parallax effects

## 🛠 Tech Stack

- **HTML5**
- **CSS3** (Tailwind + custom styling)
- **Vanilla JavaScript**
- No heavy frameworks
- Hosted on **GitHub Pages**
